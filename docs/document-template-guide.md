# คู่มือแม่แบบเอกสาร

> **สถานะ: ยังไม่เริ่มพัฒนา** — แผนข้อ 25 ห้ามเริ่มทำแบบ PDF จริง
> ก่อนมี golden sample ที่โรงเรียนรับรอง
>
> เอกสารนี้บันทึกกติกาที่ตกลงไว้แล้ว เพื่อให้เริ่มได้ทันทีเมื่อได้แบบฟอร์มจริง

## สิ่งที่ต้องมีก่อนเริ่ม

1. ไฟล์ตัวอย่างของเอกสารสามฉบับแรกที่กรอกครบและปิดข้อมูลส่วนบุคคลแล้ว (Q1)
2. รายชื่อผู้ลงนามและตำแหน่งของแต่ละเอกสาร (Q8)
3. คำตอบว่าเอกสารใดต้องมีตราครุฑ ตราโรงเรียน หรือเลขหน้า (Q9)
4. คำตอบว่าใช้ลายเซ็นภาพหรือเว้นช่องเซ็นจริง (Q10)

## กติกาที่ตกลงแล้ว

### การตั้งชื่อ placeholder

ใช้ key ที่มีชนิดข้อมูลชัดเจน **ไม่อิงข้อความไทย** เพราะข้อความบนแบบฟอร์มเปลี่ยนได้
แต่ความหมายของช่องไม่เปลี่ยน

```text
school.nameTh              procurement.referenceNo
school.addressTh           procurement.subject
requester.fullName         procurement.fiscalYearBE
requester.position         totals.subtotal
vendor.name                totals.tax
vendor.taxId               totals.grandTotal
approver.fullName          totals.grandTotalThaiText
approver.position          items[]
```

### Versioning

- แม่แบบหนึ่งฉบับ = metadata + schema ของข้อมูล + renderer component + version
- **ห้ามแก้ published template ทับของเดิม** ให้ clone เป็นเวอร์ชันใหม่
- `unique(code, version)` บังคับที่ระดับฐานข้อมูล
- เลือกแม่แบบตามชนิดงาน ปีงบประมาณ และ `effective_from`/`effective_to`

### Preview กับเอกสารจริงต่างกันอย่างไร

|              | Preview                  | เอกสารจริง                  |
| ------------ | ------------------------ | --------------------------- |
| ข้อมูล       | ข้อมูลปัจจุบัน           | frozen snapshot             |
| Watermark    | `ฉบับร่าง`               | ไม่มี                       |
| เลขที่เอกสาร | `DRAFT` (ค่าคงที่ในโค้ด) | เลขจริงที่จองใน transaction |
| เก็บไฟล์     | ไม่เก็บ                  | เก็บพร้อม sha256            |

FR-NUM-006 ห้าม Preview ใช้เลขจริงเด็ดขาด — `DRAFT_DOCUMENT_NUMBER`
ใน `src/domain/documents/document-number.ts` มีไว้เพื่อการนี้

### รูปแบบเลขที่เอกสาร

`formatDocumentNumber()` รองรับ token เหล่านี้:

| Token              | ความหมาย                         | ตัวอย่างผลลัพธ์ |
| ------------------ | -------------------------------- | --------------- |
| `{prefix}`         | คำนำหน้าจาก `document_sequences` | `ศธ04`          |
| `{running}`        | เลขลำดับ                         | `7`             |
| `{running:4}`      | เลขลำดับเติมศูนย์ 4 หลัก         | `0007`          |
| `{fiscalYearBE}`   | ปีงบประมาณ พ.ศ.                  | `2569`          |
| `{fiscalYearBE:2}` | ปี พ.ศ. สองหลักท้าย              | `69`            |
| `{fiscalYearCE}`   | ปีงบประมาณ ค.ศ.                  | `2026`          |
| `{departmentCode}` | รหัสหน่วยงาน                     | `FIN`           |
| `{documentType}`   | รหัสชนิดเอกสาร                   | `PO`            |

Token ที่ระบบไม่รู้จักจะทำให้เกิด error ไม่ปล่อยเป็นช่องว่างเงียบ ๆ

### Checklist คุณภาพ PDF (ข้อ 8.5)

ต้องผ่านทุกข้อก่อนถือว่าเอกสารหนึ่งฉบับเสร็จ:

- [ ] A4 ถูกต้องทั้ง portrait/landscape ตามแม่แบบ
- [ ] ฟอนต์ไทยไม่แตก วรรณยุกต์ไม่หาย และค้นหาข้อความใน PDF ได้
- [ ] ตารางไม่ล้นขอบ และ header ซ้ำเมื่อขึ้นหน้าใหม่
- [ ] จำนวนเงินใช้รูปแบบเดียวกันทั้งระบบ (`formatSatang()`)
- [ ] ไม่มีบรรทัดลายเซ็นแยกไปหน้าถัดไปโดยไม่มีชื่อผู้ลงนาม
- [ ] เลขหน้าถูกต้อง
- [ ] พิมพ์ด้วย scale 100% แล้วระยะขอบผ่านการตรวจจริง
- [ ] Metadata ของ PDF ไม่เปิดเผยข้อมูลภายในที่ไม่จำเป็น
- [ ] ทดสอบด้วยรายการอย่างน้อย 50 แถว และชื่อยาวผิดปกติ
- [ ] ทดสอบข้อความไทยปนอังกฤษ และเลขไทย/อารบิก
